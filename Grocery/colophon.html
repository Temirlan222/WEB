How this site was made

Files and responsibilities

This student project describes Lido in Astana. Temirlan is responsible for the home and products pages. Murager is responsible for prices and delivery. Saparali Shalkar is responsible for contacts and this page. The six HTML files belong in the same folder, with photographs inside images/.

These pages use plain HTML and Bootstrap from a CDN, with a small external CSS file for colours. Bootstrap's JavaScript bundle powers the menu; there is no custom JavaScript. Opening a file directly in a browser displays its headings, text, links and photographs. Relative links connect the local pages.

Editing and checking

Sublime Text can edit these files. On a Mac, press Command + S to save, then reload the browser. The telephone link uses a simple address:

<a href="tel:+77479052505">
    Call Lido
</a>

Check each saved file with the W3C Nu Html Checker. A successful result reads Document checking completed. No errors or warnings to show.

Telephone link and sources

The tel: link asks the device to open a calling app. The visitor can then call the shop to discuss delivery. The product request demo on the Products page does not send customer details anywhere.

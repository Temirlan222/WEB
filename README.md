Lido Grocery Store

This project is a simple website about Lido Grocery Store in Astana. It was created for Assignment 1 in Introduction to Web Technologies. The website uses HTML without CSS, JavaScript, or frameworks.

The project contains six pages: Home, Products, Prices, Delivery, Contacts, and Colophon. Visitors can explore product categories, check example prices, find contact details, and learn how the website was made.

Temirlan is responsible for the home, products, and prices pages. Saparali Shalkar is responsible for delivery, contacts, and colophon.

To open the website, download the repository and open Grocery/index.html in a browser. Keep the HTML files and images in their original folders so navigation and photographs work correctly.

The product request form demonstrates HTML controls. It has no backend and does not send requests to the store.

All six pages passed the W3C Nu Html Checker with zero errors and warnings during the latest validation.
